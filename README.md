## 🏠 Host : serveur multimédia (stack *arr)

| Outil | Ce que ça fait |
|---|---|
| [Jellyfin](https://github.com/jellyfin/jellyfin) ⭐🐳🔓 | Un Netflix perso : diffuse vos films et séries sur tous vos appareils, sans abonnement. |
| [Radarr](https://github.com/Radarr/Radarr) 🐳🔓 | Gère la bibliothèque de films : suivi, import, renommage et rangement automatiques. |
| [Sonarr](https://github.com/Sonarr/Sonarr) 🐳🔓 | L'équivalent de Radarr pour les séries, épisode par épisode. |
| [Prowlarr](https://github.com/Prowlarr/Prowlarr) 🐳🔓 | Centralise les indexeurs et les transmet à Radarr et Sonarr. |
| [Bazarr](https://github.com/morpheus65535/bazarr) 🐳🔓 | Trouve et télécharge automatiquement les sous-titres des films et séries. |
| [Jellyseerr](https://github.com/Fallenbagel/jellyseerr) 🐳🔓 | Une jolie interface pour demander un film ou une série, qui l'envoie ensuite à Radarr ou Sonarr. |
| [qBittorrent](https://github.com/qbittorrent/qBittorrent) ⭐🐳🔓 | Client torrent léger, sans pub, avec une interface web pour le piloter à distance. |

> 💡 **Astuce** : montez le même `/Media` dans tous les conteneurs pour que les hardlinks fonctionnent (import instantané, aucun espace disque en double).
